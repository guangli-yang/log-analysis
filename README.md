# 日志分析工具 (Log Analyzer)

一款功能强大的跨平台日志分析桌面应用程序，专为高效查看和分析日志文件而设计。

## 功能特性

### 📁 文件操作
- **打开单个文件**：支持 .log, .txt 等多种日志格式
- **打开文件夹**：批量加载文件夹内的所有日志文件
- **历史记录**：自动保存最近打开的文件，支持快速重新打开
- **文件切换**：在多个文件间快速切换

### 🔍 搜索功能
- **实时搜索**：输入关键字后立即显示结果
- **正则表达式**：支持高级正则表达式搜索
- **搜索选项**：区分大小写、全字匹配
- **结果导航**：在匹配项间快速跳转，支持循环跳转
- **快捷键**：Ctrl+F 打开搜索对话框

### 📊 错误分析
- **自动检测**：自动扫描日志中的错误关键字
- **关键字配置**：预设错误关键字库，支持自定义添加、编辑、删除
- **智能提示**：为每个错误提供描述信息和处理建议
- **导出配置**：支持导出错误关键字配置为JSON文件

### 🎯 行号跳转
- **快速跳转**：通过行号快速定位到指定行
- **输入验证**：检查行号范围和有效性
- **快捷键**：Ctrl+G 打开跳转对话框

### 🎨 界面特性
- **主题切换**：支持深色和浅色主题
- **字体调整**：可调整字体大小（8px - 32px）
- **虚拟滚动**：高效处理大文件（100MB+）
- **双向滚动**：支持垂直和水平滚动
- **响应式设计**：适配不同屏幕尺寸

## 技术栈

- **Electron 28.3.3**：跨平台桌面应用框架
- **React 18.2.0**：用户界面库
- **TypeScript 5.3.0**：类型安全的JavaScript
- **Vite 5.4.21**：快速的构建工具
- **react-window 1.8.10**：虚拟滚动库，处理大文件性能优化

## 系统要求

- **操作系统**：Windows 10/11 及以上
- **内存**：至少 2GB 可用内存（推荐 4GB+）
- **磁盘空间**：100MB 可用磁盘空间

## 安装说明

### 便携版
直接运行 `Log Analyzer.exe` 即可使用，无需安装。

### 安装版
运行安装程序 `Log Analyzer Setup.exe`，按照安装向导完成安装。

## 使用说明

1. 打开应用
2. 点击"打开文件"或"打开文件夹"加载日志
3. 使用搜索功能查找关键字
4. 查看错误分析面板了解问题
5. 使用 Ctrl+G 跳转到指定行号
6. 使用 Ctrl+F 打开搜索对话框
7. 点击工具栏右侧的主题按钮切换深色/浅色主题

## 快捷键

- `Ctrl+F`：打开搜索对话框
- `Ctrl+G`：打开行号跳转对话框
- `Enter`：跳转到下一个搜索结果
- `Shift+Enter`：跳转到上一个搜索结果
- `Esc`：关闭对话框
- `Ctrl++`：增大字体
- `Ctrl+-`：减小字体
