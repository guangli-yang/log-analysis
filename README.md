# Log Analyzer - 日志分析工具

跨平台日志分析桌面应用程序，基于 Electron + React + TypeScript 构建。

---

## 功能特性

### 📂 日志文件管理
- 支持打开多个日志文件（工具栏下拉选择切换）
- 历史记录管理（点击工具栏"历史记录"按钮查看）
- 支持拖拽打开文件、右键新建空白文件
- **全新欢迎页**：未打开文件时显示引导卡片（拖放区 + 打开文件 + 导入配置 + 最近文件）

### 🗂️ 项目管理
- 顶部工具栏 **项目下拉选择器**，全局切换当前项目
- 每个项目独立管理模块日志和模块负责人表
- 关键词、AI 配置保持全局共享
- 项目配置自动保存，启动时恢复上次项目

### 🔍 搜索功能
- **搜索结果面板**：显示所有搜索结果，支持滚动浏览（虚拟列表）
- **搜索对话框**：按 `Ctrl+F` 或点击工具栏 **🔎 查找** 打开
  - 支持正则表达式、区分大小写、全词匹配
  - 三种选项可任意组合使用
  - 支持上下方向键浏览搜索历史
- **搜索词高亮**：支持多个关键词同时高亮显示（10种颜色）
- **快捷搜索标签**：保存常用搜索词条，点击快速搜索
- **搜索历史**：点击 📜 按钮查看历史搜索记录
- 快捷键导航（`Enter` / `Shift+Enter` / `F3`）
- **可调布局**：搜索结果面板高度可自由拖拽调整

### ⚠️ 错误分析
在 **分析面板 → 错误标签** 中，点击"开始分析"按钮，根据用户配置的 **错误关键字** 在日志中搜索匹配行，显示关键字描述。

预置错误关键字：`print_err`、`copy_err`、`scan_err`、`error`、`exception`、`fatal`、`fail`、`warning`

### 💥 核心转储分析
在 **分析面板 → 核心转储标签** 中，点击"开始分析"按钮，根据用户配置的 **核心转储关键字** 搜索匹配日志。

预置核心转储关键字：`coredump`、`core dump`、`segmentation fault`、`SIGSEGV`、`core dumped`

### 📄 代码日志检索
位于 **分析面板 → 代码标签**

#### 离线模式
基于用户定义的正则表达式在本地源代码目录中检索匹配的日志打印语句。

#### 在线模式（AI）
调用 AI API（如 OpenAI GPT）分析源码文件，智能检索日志相关代码。

### 🔗 快速分析（日志与代码匹配）
位于工具栏 **🔗 快速分析** 按钮，将当前打开的日志与模块日志（代码检索结果）进行关联分析。

#### 核心概念

**模块日志文件**：从源代码中检索出的日志打印语句集合，每条记录包含代码文件路径、行号、函数名、匹配模式和提取的静态文本。来源：工具栏 → **代码检索** → 扫描源码目录 → 导出结果。

**模块负责人表**：代码路径 → 模块名称 → 负责人的映射关系，匹配成功后自动关联责任人。

#### 使用步骤
1. 单击工具栏 **🔗 快速分析** 按钮
2. 勾选要参与匹配的模块（可多选）
3. 单击 **🔍 开始匹配**——系统自动按源代码行号 + 关键词分词进行匹配
4. 查看匹配结果，附带模块负责人信息

> **注意**：日志文件需包含 `L<行号>: <内容>` 格式的行才能匹配

### 📊 数据管理面板
位于工具栏 **数据管理** 按钮，统一管理当前项目的配置数据：

| 标签页 | 功能 |
|--------|------|
| 模块负责人表 | 代码路径/模块名称/负责人内联编辑，支持新增、删除、一键清空 |
| 模块日志表 | 按文件分组，默认折叠，点击展开查看并编辑逐条明细（代码文件/行号/函数名/匹配模式/匹配文本），支持搜索 |

面板顶部可切换项目、新建项目、删除项目。

### 📋 日志提取
点击工具栏 **✂️ 日志提取** 按钮：
- **倒数第N个作业**：输入作业序号，提取该作业的日志段（基于作业关键字）
- **最后开机/重启**：提取系统启动后的日志（检测 boot/startup/开机/启动 等模式）
- **最后错误**：提取最后一个错误前后的日志上下文（基于错误关键字）
- **自定义关键词**：输入自定义关键字提取相关日志

### 🤖 AI 智能助手
点击工具栏 **🤖 AI** 按钮打开 AI 对话框：
- 配置 API 地址、Key、模型名称，支持测试连接
- 选择上下文模式：无 / 选中内容 / 全部日志 / 最近N行（100/200/500/1000）
- 支持拖拽移动、点击外部不退出（独立浮动窗口）
- 一键复制分析结果，可直接分享

### 🎨 高亮样式
在 **关键词设置 → 高亮设置** 中配置：背景颜色、文字颜色、边框颜色

### 📌 编辑功能
- 双击日志行进入编辑模式
- 支持 `Ctrl+S` 保存、`Escape` 取消
- 复制选中文本（`Ctrl+C`）
- 修复了编辑保存后内容显示错乱的问题

### 🎛️ 界面布局
- 可拖拽分隔条自由调整各面板高度
- 日志查看器和搜索结果面板的高度比例可自由调整

### ⚙️ 配置管理
- **关键词设置**（工具栏 ⚙️ 按钮）：
  - 错误关键字：用于错误分析
  - 作业关键字：用于日志提取
  - 忽略关键字：用于关键词过滤
  - 代码检索：用于离线代码检索的正则表达式模式
  - 核心转储关键字：用于核心转储分析
  - 高亮设置：用于高亮样式
  - **全部标签页支持内联编辑**（点击关键词/描述/模式名称/正则表达式即可直接修改）
- **导入/导出配置**：在关键词设置对话框中
- **用户角色选择**：支持研发/测试角色切换

## 使用说明

### 1. 安装依赖

```bash
npm install
```

### 2. 开发模式

```bash
npm run dev
```

启动后会自动打开 Electron 应用窗口。

### 3. 构建生产版本

```bash
npm run build
```

构建完成后，输出文件位于 `dist` 目录。

### 4. 打包分发

```bash
npm run dist
```

生成可安装的分发包（Windows 支持 portable 便携版和 nsis 安装包）。

## 操作指南

### 打开日志文件
- 点击工具栏的 **📄 打开文件** 按钮选择日志文件
- 也支持直接拖拽文件到窗口

### 使用搜索功能

**搜索结果面板**（始终显示在日志下方）：
- 显示所有搜索结果列表
- 支持快捷搜索标签（点击标签快速搜索）
- 支持搜索历史（点击 📜 按钮查看）
- 支持多个关键词高亮（高亮条可删除）

**搜索对话框**（按 `Ctrl+F` 或点击工具栏 **🔎 查找** 打开）：
1. 输入搜索关键词
2. 可选：启用 **匹配大小写**、**全词匹配**、**正则表达式**
3. 点击 **在当前文件中查找** 执行搜索
4. 使用 **查找上一个/下一个** 或按 `Enter`/`Shift+Enter` 导航结果

### 关键词过滤
1. 点击工具栏的 **🔍 关键词过滤** 按钮
2. 系统将根据 **忽略关键字** 设置过滤日志内容
3. 过滤后的内容会保存为新文件（文件名添加 `_filtered` 后缀）

### 配置关键字
1. 点击工具栏的 **⚙️ 关键词设置** 按钮
2. 在弹出的对话框中切换不同的标签页
3. 点击 **"应用"** 保存配置

### 使用分析功能
1. 点击工具栏的 **📊 分析** 按钮打开分析面板
2. 分析面板包含以下标签页：
   - **错误**：根据错误关键字分析日志，列出所有匹配行
   - **代码**：代码日志检索（离线/在线模式）
   - **核心转储**：根据核心转储关键字分析日志

### 代码日志检索

#### 离线检索
1. 在分析面板切换到 **"代码"** 标签
2. 选择 **"离线"** 模式
3. 点击 **"开始检索"** 按钮
4. 选择源代码目录
5. 系统将使用预定义的正则表达式模式检索匹配的代码

#### 在线检索（AI）
1. 先配置 AI API（点击 AI 按钮配置）
2. 在分析面板切换到 **"代码"** 标签
3. 选择 **"在线"** 模式
4. 点击 **"AI 检索"** 按钮

### 快速分析（日志与代码匹配）

> 快速分析需要先准备好**模块日志文件**和**模块负责人表**两项数据。

#### 准备工作

**步骤一：创建项目**
1. 顶部工具栏 → 项目下拉 → 单击 **＋** → 输入项目名称
2. 项目目录自动在 `config/` 下创建

**步骤二：生成并导入模块日志文件**
1. 分析面板 → **代码** 标签 → 离线检索 → 选择源码目录 → 开始检索
2. 工具栏 → **📥 导入配置** → 输入项目名称 → 选择模式 → **导入模块日志配置**

**步骤三：导入模块负责人表**（可选但推荐）
1. 工具栏 → **📥 导入配置** → 输入项目名称 → **导入模块负责人配置**

#### 执行匹配
1. 打开一个日志文件（需包含 `L<行号>: <内容>` 格式）
2. 工具栏 → **🔗 快速分析** → 勾选模块 → **开始匹配**

### 数据管理
1. 工具栏 → **数据管理** → 可切换项目 / 新建项目
2. **模块负责人表**：点击单元格直接编辑，修改自动保存
3. **模块日志表**：点击分组展开查看明细，支持编辑逐条条目
4. 搜索框输入关键词可跨文件、跨条目搜索匹配分组

### 日志提取
1. 点击工具栏的 **✂️ 日志提取** 按钮
2. 选择提取模式并配置参数
3. 点击 **"开始提取"** 获取结果

### AI 智能助手
1. 点击工具栏的 **🤖 AI** 按钮打开 AI 对话框
2. 首次使用需要配置 API（点击 ⚙️ 设置图标）
3. 选择上下文模式并输入问题
4. 点击发送获取分析结果

### 跳转行号
1. 点击工具栏的 **📍 跳转行号** 按钮（或使用快捷键 `Ctrl+G`）
2. 输入目标行号
3. 点击跳转

## 技术栈

- **前端框架**：React 18
- **语言**：TypeScript
- **桌面框架**：Electron
- **构建工具**：Vite
- **本地数据库**：Dexie.js (IndexedDB) — 用于全局配置存储
- **项目数据存储**：文件系统 `config/<项目>/` JSON
- **样式**：CSS

## 项目结构

```
log-analyzer/
├── electron/           # Electron 主进程代码
│   ├── main.ts        # 主进程入口 + IPC 接口
│   └── preload.ts     # 预加载脚本
├── src/               # React 前端源码
│   ├── components/    # React 组件
│   ├── utils/         # 工具函数（db.ts 全局配置 Dexie）
│   ├── App.tsx        # 应用入口
│   └── types.ts       # 类型定义
├── resources/         # 打包资源
│   └── config/        # 示例项目配置（随 electron-builder extraFiles 发布）
├── config/            # 运行时项目配置（开发模式在工作区，生产模式在 exe 同级）
│   └── <项目名>/
│       ├── code-search/       # 模块日志文件
│       └── module-mapping/    # 模块负责人表
├── dist/              # 构建输出目录
├── release-final/     # 分发包输出目录
└── package.json       # 项目配置
```
